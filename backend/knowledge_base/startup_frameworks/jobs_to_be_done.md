# Jobs-to-be-Done (JTBD) & MVP Prioritization Framework

Customers don't buy products; they hire products to perform a specific job in their daily lives or businesses.

## The JTBD Formula:
"When I am [Context/Situation], I want to [Action/Motivation], so that I can [Desired Outcome/Emotional Benefit]."

## MVP Scope Constraints:
- **P0 Must-Have**: Features that perform the core Job-to-be-Done without which the user cannot achieve the main outcome.
- **P1 Should-Have**: Convenience features that reduce friction but are not blocking.
- **P2 Future Features**: Integrations, white-labeling, advanced analytics, and multi-team admin permissions.

## Ruthless MVP Prioritization:
- If a feature takes more than 2 weeks to build for v1, move it to P1 or P2.
- Solve one specific problem exceptionally well for one target audience before expanding scope.

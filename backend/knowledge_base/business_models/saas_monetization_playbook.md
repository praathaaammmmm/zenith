# SaaS Monetization & Pricing Models Playbook

Structuring early-stage pricing tiers to maximize conversion and expansion revenue.

## 1. Product-Led Growth (PLG) Freemium
- Free tier includes core basic features with usage caps (e.g., 3 projects or 100 API queries per month).
- Instant upgrade prompt when user hits 80% usage threshold.

## 2. Flat-Rate vs. Per-Seat Pricing
- Per-seat pricing works best when value scales with team size (e.g., collaboration tools, CRMs).
- Usage-based/feature-gated pricing works best when value scales with volume (e.g., API calls, AI tokens, reports generated).

## 3. Early Adopter Discount Strategy
- Offer a 30% lifetime discount to the first 100 paying customers in exchange for case study rights and weekly feedback calls.
